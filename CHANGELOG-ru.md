# Журнал изменений

Все значимые изменения проекта будут документироваться в этом файле.

Формат следует духу Keep a Changelog, а проект использует семантическое версионирование.

## [1.1.0] - 2026-11-11

### Добавлено

- Постоянная панель вкладок с выделением активной: `0` — обзор, `1–8` — разделы Vault. Вкладки сохраняют открытый экран, фильтр и выбранную строку; на узком терминале панель переносится на несколько строк.
- Полная конфигурация auth methods, включая LDAP, свойства mount и tuning.
- Просмотр дополнительных API-ресурсов раздела по `b`, выбор нестандартных PKI/Transit/Database/AWS mount-ов по `m` и полные метаданные KV v2 по `m` в деталях secret.
- Команды `:read <путь> [key=value ...]` и `:list <путь>` для чтения произвольных Vault API-путей. JSON/YAML-просмотр сохраняет полный ответ, включая warnings, lease metadata и `key_info` списков.
- Открытие полного значения свойства по `Enter` с переносом строк и прокруткой; копирование значений и JSON в деталях.
- Две панели Policies: список политик сверху и автоматически обновляемое содержимое выбранной политики снизу. `PgUp/PgDn` прокручивают нижнюю панель, `Enter` открывает полный экран.
- Индикаторы диапазона видимых строк, общего количества и наличия содержимого выше/ниже во всех таблицах, текстовых и JSON/YAML-просмотрах; отдельные индикаторы обеих панелей Policies.
- Поддержка русской раскладки и Caps Lock для буквенных hotkey, включая настраиваемые привязки; Unicode-ввод через curses `get_wch`.
- Автотесты навигации, полноты данных, панелей Policies, индикаторов и hotkey; отдельная проверка данных вкладок по Vault CLI на работающем сервере.

### Изменено

- Детали mount-ов, Transit, Identity, Database, AWS, PKI и token inspector сохраняют все возвращаемые поля вместо фиксированной выборки. Пустые строки, `false`, `0`, `[]`, `{}` и `null` отображаются раздельно.
- **Изменены hotkey:** JSON-просмотр перенесён с `J` на `F2`, копирование JSON — с `C` на `F4`, переход в конец — с `G` на `End`. Буквы в обоих регистрах теперь выполняют одно действие; `y` по-прежнему открывает YAML.
- Ввод команд и фильтров сохраняет исходную раскладку и регистр без преобразования в hotkey.
- Ошибка чтения одной коллекции не скрывает доступные соседние коллекции. Ошибки отдельных ресурсов отображаются явно; `!` открывает полный текст ошибки текущего экрана.

### Исправлено

- Потеря полей при подготовке данных к отображению и обрезание длинных значений в JSON/YAML.
- Перехват цифр и буквенных hotkey во время ввода фильтра.
- Прокрутка до последней строки таблицы, расчёт видимой области и синхронизация preview с выбором и фильтром Policies.
- Обновление данных по `r`: очистка кеша, повторное чтение в raw-режиме и обновление текстовых экранов политик.
- Сохранение устаревшего состояния вкладок и статуса подключения после смены контекста.
- Исчезновение разделительной линии Policies после добавления индикаторов прокрутки.

## [1.0.0] - 2026-06-22

### Добавлено

- Первый публичный релиз VaultUI Python.
- Однофайловая реализация на Python 3.8 с минимальными runtime-зависимостями.
- TUI на curses для просмотра HashiCorp Vault.
- Dashboard со статусом seal, версией Vault, HA-деталями, storage backend, счётчиками ресурсов и быстрой навигацией.
- Браузер secret engines с поддержкой KV, PKI, Transit, Identity, Database, AWS и generic mounts.
- Браузер KV v2 path, просмотр secret, копирование в clipboard, история версий и diff между версиями.
- Экраны policies, auth methods, PKI certificates/roles, Transit keys, Identity entities/groups, Database, AWS и token inspector.
- Переключение контекстов через `~/.vaultui.yaml`.
- Аутентификация через token, userpass и AppRole.
- Command palette и настраиваемые keybindings.
- Clipboard с автоочисткой скопированных secrets.
- Headless-подкоманда `get` с JSON-выводом.
- Скрипт заполнения локального dev Vault: `seed-vault-dev.sh`.
- Архитектурные диаграммы PlantUML в `diagramms/`.
- README-файлы на английском и русском языках.
